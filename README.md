# 2027 Calendar Judging

Live judging and public voting site for the 2027 calendar contest.

- Frontend: GitHub Pages
- Shared backend: Supabase (`2027 Calendar Judging`)
- Mobile-friendly judge portal
- Admin cutoff tie-breaks
- Top 14 calendar winners → defined Top 5 → Cover/Centerfold final

The private admin key is intentionally not stored in this repository.
